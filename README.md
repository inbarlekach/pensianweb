# אבטיפוס: זיהוי הזדמנויות בדמי ניהול פנסיה

> **אבטיפוס לימודי.** הפרופיל (עידו) פיקטיבי. אין חיבור לחשבונות פנסיה אמיתיים, ושום דבר כאן אינו ייעוץ פנסיוני.

## הרצה (Windows, Python 3.12)
```
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m pytest -q
.venv\Scripts\python -m uvicorn app.main:app --port 8000
```
- **הדמו:** http://localhost:8000
- **דוח הבדיקות:** `tests/REPORT.md`, נכתב מחדש בכל ריצה.

## רענון נתוני שוק (למפעיל בלבד)
```
.venv\Scripts\python scripts\refresh_market_data.py
```
- הסקריפט מושך את נתוני "פנסיה-נט" מ-data.gov.il, מאמת אותם ושומר snapshot חדש ב-`data/market/`.
- `manifest.json` מתעד את המקורות, את מועד האיסוף ואת הרשומות שנפסלו.
- אם הרענון נכשל, ה-snapshot הקודם נשאר והממשק מציג אזהרה.

## מה הדמו עושה
1. טוען את פרופיל ההדגמה. החיבור למקור המידע מדומה ומסומן ככזה.
2. משווה את דמי הניהול של עידו לממוצעים **שנגבו בפועל** ב-9 קרנות הפנסיה המקיפות בפנסיה-נט.
3. מחשב בקוד את החיסכון בשנה הראשונה ואת הפער בצבירה בגיל 67, בשלושה תרחישי תשואה.
4. מפיק ממצאים בשתי רמות סיכון, מדורגים לפי סיכון ואחר כך לפי סכום. כל ממצא מגיע עם מקור, רמת ודאות, הנחות ומגבלות.

## מגבלות ידועות
- **נתוני השוק הם ממוצעים, לא הצעות.** לכן אף ממצא אינו ברמת ודאות 1.
- **ניסוח הממצאים** נעשה כרגע בתבנית קבועה, לא במודל AI, וכך הוא מסומן בממשק. ספק AI יתחבר דרך `app/agents/base.py`.
- **הנחות שעדיין לא אושרו:** ההנחות ב-`data/assumptions.json` מסומנות `pending_approval`.
- **לא כלול בגרסה זו:** כיסוי ביטוחי, קצבה חודשית ותשואות הקרנות.
